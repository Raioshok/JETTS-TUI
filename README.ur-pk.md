# Jetts-TUI

Jetts-TUI ٹرمینل پر مبنی AI ورک اسپیس ہے۔ اس میں فل اسکرین TUI، ایجنٹ، میموری، ذیلی ایجنٹس، شیڈول شدہ کام اور میسجنگ انٹیگریشنز شامل ہیں۔ اسی انجن کے ڈیسک ٹاپ اور ویب حصے بھی اس ریپوزٹری میں موجود ہیں۔

یہ مختصر رہنما انسٹالیشن کے لیے ہے۔ مکمل اور تازہ معلومات کے لیے [مرکزی README](README.md) اور [ریپوزٹری کی دستاویزات](website/docs) دیکھیں۔

## انسٹالیشن

[یہ ریپوزٹری](https://github.com/Raioshok/JETTS-TUI) کلون یا ڈاؤن لوڈ کریں، پھر اپنے سسٹم کے مطابق مقامی سیٹ اپ اسکرپٹ چلائیں۔ کسی دوسرے پروجیکٹ کے ڈومین سے انسٹالر استعمال نہ کریں۔

Linux، macOS یا WSL2:

```bash
bash setup-jetts-tui.sh
```

Windows PowerShell:

```powershell
.\setup-jetts-tui.ps1
```

اگر PowerShell مقامی اسکرپٹس کو روکے تو صرف اس عمل کے لیے عارضی پالیسی استعمال کریں:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup-jetts-tui.ps1
```

دوبارہ چلانے پر اسکرپٹس موجودہ ماحول کو استعمال کرتے ہیں۔ فراہم کنندہ کی ترتیب بعد میں کرنے کے لیے Linux/macOS پر `--skip-setup` یا Windows پر `-SkipSetup` استعمال کریں۔

## آغاز

```bash
jetts-tui          # ٹرمینل انٹرفیس کھولیں
jetts-tui setup    # فراہم کنندگان اور ٹولز ترتیب دیں
jetts-tui model    # فراہم کنندہ اور ماڈل منتخب کریں
jetts-tui doctor   # مسائل کی تشخیص کریں
```

موجودہ ماڈل فراہم کنندگان اور ہوسٹڈ سروسز کے رابطے برقرار ہیں؛ نام بدلنے سے ان کا رخ تبدیل نہیں ہوتا۔ `FREEIDE_HOME` اور `~/.freeide` جیسے پرانے تکنیکی نام مطابقت کے لیے برقرار رکھے گئے ہیں۔
