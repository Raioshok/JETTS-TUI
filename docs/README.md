# Jetts-TUI documentation

Jetts-TUI is a terminal-first AI workspace. The Ink TUI is the interactive chat interface; the Python runtime powers its tools, sessions, memory, and messaging gateway.

Start with [installation](getting-started/installation.md), then [quickstart](getting-started/quickstart.md). For configuration, see [providers](integrations/providers.md), [configuration](user-guide/configuration.md), and [security](user-guide/security.md).

Developer references live in [developer-guide](developer-guide/architecture.md). These are repository Markdown files; there is no separate documentation site.
